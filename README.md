# Кирилл Сорокин — портфолио дизайнера

Одностраничный сайт на Angular 22 и TypeScript 6. Русскоязычный адаптивный интерфейс, четыре кейса, фильтрация проектов, диалоговые окна, Telegram и скачиваемый бриф.

## Запуск

Требуется Node.js 24.19+ и npm. Из корня проекта:

```bash
npm ci --cache /tmp/portfolio-npm-cache
npm start
```

Сервер разработки использует порт 4200. `npm run build` создаёт статическую production-сборку в `dist/portfolio/browser`, которую можно разместить на любом статическом хостинге. Серверная часть не требуется.

## Проверки

```bash
npm run build
npm run test:e2e
```

Playwright проверяет настольную и мобильную версии: загрузку иллюстраций, фильтры, все кейсы, клавишу Escape, восстановление фокуса, навигацию, валидацию и содержимое скачанного брифа. При наличии используется `/usr/bin/chromium`; другой путь можно задать через `CHROMIUM_EXECUTABLE_PATH`. Если системного Chromium нет, установите браузер командой `npx playwright install chromium`. Сервер для тестов запускается автоматически.

## Содержание и настройки

- Проекты и тексты кейсов: `src/app/app.component.ts`.
- Разметка, биография и контакты: `src/app/app.component.html`.
- Дизайн и адаптивность: `src/styles.css`.
- Превью проектов: `src/app/project-art.component.ts`; авторские SVG-иллюстрации находятся в `public/images`.
- Telegram: `https://t.me/fabakc`.

DSTU Connect описывает предоставленную роль Кирилла в команде; экран — иллюстрация дизайнерского направления. Orbit, Forma и «Вне кадра» — явно обозначенные демонстрационные концепты, созданные по описанию опыта. У них нет вымышленных заказчиков, метрик или заявлений о выпуске.

Форма брифа сохраняет введённые данные только в скачиваемый `.txt` и не отправляет их на сервер. Готовый файл пользователь может отправить в Telegram самостоятельно. Шрифты и иллюстрации поставляются локально; внешние запросы для отображения сайта не нужны.
